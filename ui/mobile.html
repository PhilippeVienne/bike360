          Aide

          Le parcours (onglets du bas)

          1. Fichiers : coche les sessions de ta balade.

          2. Repérer : regarde, saute aux moments forts (◀ ▼ ▶), pose des clips (⟦ Début, Fin ⟧, ＋15 s).

          3. Montage : ordre, montage auto, finition, musique, flou.

          4. Exporter : destination, qualité, puis export.

          Gestes

          Image : toucher pour lecture / pause, glisser pour orienter, pincer pour le champ ; « Vue » pour avant / pilote / brut, horizon et rotation.

          ⛶ : vidéo en plein écran.

          Frise : toucher pour aller à un instant, glisser pour balayer, pincer pour zoomer ; glisser le bord d'un clip sélectionné ou un ◆ pour l'ajuster.

          Clips

          Touche un clip pour l'éditer : bords au dixième, cadrage et points clés ◆, suivi d'un compagnon 🎯, points de vitesse ⏩.
